Deployment Architecture: Vercel Staging to Plesk Production

Seamless two-stage delivery pipeline: instant automated staging previews on Vercel for rapid feedback, followed by hardened deployment on Plesk.

Stage 1: Vercel Staging Deployment

  1. Push project repository to GitHub (e.g. github.com/your-org/azrentalguy).
  2. Import repo in Vercel Dashboard. Vercel automatically detects Next.js 15.
  3. Set Environment Variables in Vercel project settings:
    NEXT_PUBLIC_BUSINESS_NAME="J-Bone Industries LLC" NEXT_PUBLIC_PHONE="(707) 326-5592" NEXT_PUBLIC_EMAIL="jbone@azrentalguy.com" NEXT_PUBLIC_TAX_RATE="0.086" DATABASE_URL="file:./azrentalguy.db" # or Supabase/Postgres connection string AI_GATEWAY_API_KEY="your-api-key" ADMIN_ACCESS_PIN="secure-pin-code"
  4. Deploy to obtain staging URL (e.g. https://azrentalguy-staging.vercel.app) for live review.

Stage 2: Plesk Production Deployment (azrentalguy.com)

  1. Log in to the Plesk Hosting Panel for azrentalguy.com.
  2. Under Websites & Domains, select Node.js (supported natively in Plesk Obsidian).
  3. Set Node.js Version: v20.x or v22.x.
  4. Set Application Mode: production.
  5. Set Application Root: /httpdocs or /httpdocs/azrentalguy.
  6. Set Application Startup File: server.js (Next.js standalone server) or node_modules/next/dist/bin/next with argument start.
  7. Run npm run build inside Plesk SSH or Web Terminal.
  8. Point domain DNS records or enable the Node.js application proxy. Plesk automatically manages the Let's Encrypt SSL certificate.
